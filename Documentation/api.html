Sets whether the Z value of a 3MF toolpath layer is the top or the base of the layer. EOS layers are given by their top, so with Base the smallest layer distance of the toolpath is added to every layer Z. With Top, a layer at Z 0 fails with LAYERZINVALID. A first layer whose Z equals the layer distance fits both conventions and is reported in the conversion log.

struct EOSTaskPoint

MemberTypeDescription
Xdouble
Ydouble
LaserPowerdoubleLaser power in Watts at this point. In a hatch block, the power ramps linearly from the first to the second point of a hatch. In a polyline block, it is the power of the vector that ends at this point. Values of 0 or less use the DefaultLaserPower of the block.
ScanSpeeddoubleScan speed in mm/s at this point, with the same rule as LaserPower. Values of 0 or less use the ScanSpeed of the block.
LaserFocusdoubleEOS focus value at this point, from 0.0 (fully defocused) to 1.0 (fully focused), with the same rule as LaserPower. It is not a distance. Only used if HasLaserFocus is true.
HasLaserFocusboolIf false, the focus of the block is used. Focus values can be 0, so they need this flag.
TimestampdoubleEOS timestamp in microseconds that the EOS SDK reported with this point when the task was read: the time of the hatch for both points of a hatch, and of the polyline start or coordinate for a polyline point. The end point of a polyline, which has none, repeats the previous one. Ignored when writing.
